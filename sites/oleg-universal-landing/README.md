# Юридическая помощь Олега — универсальный лендинг

**Статус 20.11.2026:** V1 создан как изолированная тестовая разработка. НЕ опубликован и не подключён к реальному Битрикс24. Два действующих сайта Олега не изменены; Яндекс Директ не запущен.

## Реализовано
Одна адаптивная страница с телефоном, формой, 8 направлениями юридической помощи, этапами и FAQ. Нет выдуманных отзывов, «24/7», наград или гарантий. Номер +7 (917) 205-21-25 проверен на обоих существующих сайтах 20.11.2026.

## Битрикс24
Серверный PHP-адаптер, секреты только в окружении хостинга. Одноразовый CSRF, honeypot, ограничение частоты, строгое происхождение запроса и HTTPS API. Путь обращения: поиск дублирующего контакта по телефону, создание контакта при необходимости, создание сделки в заданной воронке и у заданного ответственного, чтение сделки с проверкой ID/CONTACT_ID. Отсутствие подтверждения не выдаётся за успех. Идемпотентность блокирует повтор той же заявки; при неопределённом исходе нужна ручная проверка без автоматического повторения. В приватной квитанции только статус, идентификатор CRM и время, без данных клиента.

Переменные сервера без публикации токенов:
- OLEG_LANDING_PUBLIC_ORIGIN — HTTPS-адрес нового домена без /;
- OLEG_BITRIX_WEBHOOK_URL — вебхук только существующего b24-xlzm11.bitrix24.ru с разрешениями CRM, вне Git и страницы;
- OLEG_BITRIX_CATEGORY_ID — подтверждённый номер воронки;
- OLEG_BITRIX_ASSIGNED_BY_ID — подтверждённый ID ответственного Олега;
- OLEG_LANDING_STATE_DIR — приватная директория вне webroot;
- OLEG_BITRIX_SOURCE_ID — необязательное поле, только если источник есть в CRM.

Пока параметры не заданы, сервер возвращает недоступность, без ложной успешной заявки. Телефон работает независимо.

## SEO / Директ
Тестовая сборка имеет noindex и robots Disallow. Генератор seo/build_release.py выпускает индексируемую копию только после проверки нового домена, отдельного счётчика Метрики и утверждённого HTML документа о персональных данных; добавляет canonical, OG URL, sitemap.xml, robots.txt. Текущий privacy.html намеренно содержит предупреждение и НЕ допускается в публичную сборку.

Метрика грузится только после согласия. Цели: landing_phone_click, landing_topic_selected, landing_crm_accepted (только после успешного CRM readback). Файл seo/direct-structure.csv содержит черновую структуру рекламных направлений. Кампании не созданы, расходы не запущены. Темы семейного права и потребителей лучше рекламировать на уже действующие специализированные сайты, чтобы не конкурировать с собой.

Одностраничник оптимален для широких юридических запросов, но высокие позиции по множеству узких услуг могут потребовать отдельных профильных страниц позднее. SEO/GEO-структура не гарантирует попадание в выдачу ИИ или поисковиков.

## Блокеры перед публикацией
1. Новый домен и SSL.
2. Утверждённая политика ПДн с настоящими реквизитами оператора, сроками, контактами и законным основанием обработки; сверить с Олегом.
3. Подключённый серверный вебхук с минимальными правами + подтверждённые категория воронки и пользователь. Не менять текущие две CRM-формы и роботов.
4. Проверка одного контролируемого обращения: номер реальной сделки, совпадающий контакт, источник, UTM, уведомление Олегу. Прочитать подтверждение из CRM.
5. Отдельный счётчик Метрики, согласие, тест истинной цели и авторизованные Вебмастер/GSC. После этого реклама, её маркировка и бюджет по отдельному решению.

## Тестирование
PHP lint, PHP unit-тесты, проверка DOM и JS, HTTP-тесты с отключённым CRM, мобильная визуальная проверка; реальный CRM E2E — отдельный release gate. Из-за отсутствия утверждённых реквизитов и отдельного домена публичная сборка сейчас не выпускается.
