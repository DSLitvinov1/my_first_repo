## Решение о публикации

**Не опубликовано:** невозможно соблюсти ранее утверждённые обязательные условия единого атомарного выпуска на двух физических docroots. В частности, запуск массового последовательного копирования 43 файлов может оставить сайты в смешанных версиях после падения и конфликтует с прямым ограничением существующей реализации. Нельзя заменять отсутствие реальной приёмки ссылкой на успешные offline тесты.

### Требуемый отдельный этап до релиза

1. **Отдельно согласовать опасную миграцию** Timeweb с двух физических каталогов на два docroot-симлинка, направленных через один общий версионный указатель. Пользователь ранее отдельно запретил миграцию production без полной отдельной приёмки/согласования.
2. На реальном Timeweb подтвердить поддержку симлинков веб-сервером, владельца, ACL/права, CSP, PHP-маршруты, HTTPS, доступность двух сайтов и запрет раскрытия закрытых архивов. Испытать миграцию и немедленный откат на точной топологии с планом краткого технического окна.
3. Сделать свежий backup именно перед переносом, подтвердить SHA всех 43 файлов, развернуть две полные неизменяемые версии (исходник и V15) в закрытой служебной области, проверить отсутствие неучтённых файлов и наличие выделенного общего указателя.
4. Разрешённо переключить два **идентичных старых** docroot сначала на версионный механизм, пройти реальные HTTP/DOM smoke tests без видимого изменения содержимого, и только затем **единожды** атомарно переключить общий указатель на V15. Любой сбой — немедленный контролируемый возврат к исходному содержимому.
5. Проверить обе CRM-формы с fallback телефоном/email, мобильный интерфейс, robots/sitemap/canonical/structured data, согласия на аналитику, отсутствие Qwen. Не создавать тестовые CRM сделки без необходимости.
6. Зафиксировать release SHA, production SHA, временной журнал, rollback и **реальный** статус. До этого не сливать PR и не запускать Яндекс Директ.
