# Нейрозавод: защищённая универсальная очередь — учебный этап

Область: только публичная изолированная учебная ветка, только вымышленные данные, без платежей и вмешательства в действующие проекты.

Проверенное ядро queue_core.py принимает ограниченные русскоязычные описания, назначает категорию, ведёт последовательные этапы ИИ-программиста, независимых тестов, второго ИИ-ревьюера и публикации. Установлен предел повторных исправлений. Переход к следующему заданию возможен только после подтверждённой публикации или явной остановки предыдущего. Задания без утверждённого независимого набора тестов безопасно блокируются.

Поддержаны маршруты учебных мини-CRM, калькулятора стоимости заказа и калькулятора упаковки. Для любых иных формулировок требуется новая независимая приёмка. Успешные прошлые два приложения не надо повторять. Публичная очередь inbox.json пока намеренно пуста.

Важно: ядро и 25 его проверок — не доказательство автоматического исполнения новых приложений. Для завершения интеграции необходимо связать очередь с изолированным исполнителем и существующими механизмами подготовки, независимого тестирования и публикации. Не принимать пользовательские утверждения «тесты пройдены» за реальные доказательства, не запускать пользовательский текст как команду и не выдавать файл без итоговой подписи проверенного результата.

Следующая последовательность: завершить строго трёхмодульную CRM (20/20, второй агент, публикация), затем испытать очередь на двух новых учебных заданиях подряд с реальным выполнением, контрольным восстановлением и отчётом без повторения уже пройденных экспериментов.
