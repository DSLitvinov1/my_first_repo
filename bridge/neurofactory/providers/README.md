Не изменять CORE/HANDOFF/REVIEW/COORDINATOR/SKILLS, общую очередь, рабочие GitHub Actions и основную ветку.

## Что фактически реализовано

- `offline_router.py`: детерминированный тестовый маршрут Claude / Qwen / DeepSeek, без сетевого транспорта.
- Claude → Qwen: **только** при явной ошибке `QuotaExhausted` в mock-ответе; отсутствие авторизации, временный сбой и неизвестный отказ НЕ считаются лимитом.
- Все ответы помечены `offline_mock=True`; никакие реальные запросы в нейросети не выполняются.
- Валидируется идентификатор задачи и текст запроса; запрет сетевых подклассов адаптера; не хранится текст пользовательских запросов внутри mock-адаптера.
- На одну попытку максимум одно резервное переключение; повторные вызовы, публикация и запись в очередь отсутствуют.

## Проверено

21/21 тест `test_offline_router.py` через Python standard-library unittest и успешная проверка компиляции на локальной Linux-среде 14.10.2026. После записи в GitHub повторно считаны файлы, проверено совпадение git blob SHA с испытанными локальными файлами. Это **собственные локальные** испытания, не независимое REVIEW и не Windows/CI.

## Что НЕ реализовано и заблокировано

- Нет реальной интеграции с Claude, DeepSeek или Qwen, их платными или бесплатными API.
- Доступность бесплатного веб-чата НЕ означает бесплатную доступность API. Никакие бесплатные кредиты и тарифы не подтверждены этими тестами.
- Нет автоматического переключения реальных аккаунтов, интеграции с общей очередью, секретов, оплаты, внешней доставки, пробных задач, публикации или merge.
- Нельзя запускать сетевые адаптеры до отдельной проверки бесплатного API/прав и независимого approval по точному SHA.
- HANDOFF остаётся на паузе; Q090 нельзя повторять. Весь Stage5 release по Issue #3/#4 остаётся BLOCKED.

Следующий этап PROVIDERS: отдельное документированное сравнение бесплатных локальных моделей и настоящей бесплатной API-квоты по официальным условиям; затем отдельные безопасные адаптеры только для явно подтверждённого бесплатного доступа, с лимитами затрат, таймаутами и возможностью отключения.
