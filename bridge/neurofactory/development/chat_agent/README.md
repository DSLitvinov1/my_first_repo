Нейрозавод — агент следующего задания в этот чат (Chrome / Microsoft Edge).

Проверяемые свойства: расширение читает только утверждённый промпт для следующего этапа из публичной очереди GitHub, подтверждает его контрольную сумму, работает только в явно выбранной беседе ChatGPT, не перезаписывает набранный пользователем текст, не прерывает текущий ответ ChatGPT и не делает автоматических повторов уже предпринятой отправки.

Установка (один раз):
1. Открой GitHub Actions проекта DSLitvinov1/my_first_repo, запусти или выбери завершённое задание «Neurofactory Chat Agent Install Package».
2. В конце страницы выполнения скачай вложение «neurofactory-chat-agent-chrome-edge». Распакуй архив в отдельную постоянную папку (не удаляй её после установки).
3. Открой в Chrome адрес chrome://extensions, а в Microsoft Edge — edge://extensions. Включи «Режим разработчика», нажми «Загрузить распакованное расширение» и укажи папку, где лежит manifest.json.
4. Открой существующий чат нейрозавода на chatgpt.com, закрепи значок расширения и нажми его один раз на странице именно нужного чата. Появится индикатор ON. Нажатие второй раз отключает работу.
5. Если в момент привязки новая задача уже ожидает в GitHub, расширение попробует отправить её один раз. Для следующих задач проверка выполняется приблизительно раз в три минуты, пока окно браузера и вкладка нужного чата доступны.

Примечание: расширение отправляет сообщение из уже авторизованной пользовательской сессии, не просит паролей или токенов, не использует Opera-коннектор, отдельный платный API и удалённое управление компьютером. Не устанавливается и не включается автоматически со стороны GitHub Actions.

Индикаторы на значке:
ON — расширение привязано к открытому чату;
OFF — отключено;
SEEN — расширение обнаружило собственное пользовательское сообщение с контрольной фразой в выбранном чате; это подтверждение интерфейса, а не отдельная серверная квитанция;
? — кнопка отправки могла быть нажата, но сообщение не появилось в интерфейсе или попытка неоднозначна; автоматического повтора не будет;
! — источник очереди недоступен;
NO — открытая страница не является допустимым адресом чата.

Ограничения: наличие пакета и успешных программных тестов не доказывает реальную доставку сообщения. На реальном браузере ChatGPT может менять интерфейс, и тогда отправка остановится. Проверка доставки должна быть подтверждена появлением сообщения непосредственно в нужном чате. При ошибке не устанавливай второй экземпляр и не нажимай повторно вслепую. Никаких других программ или пользовательских процессов агент не закрывает.

Для просмотра понятной диагностики открой «Управлять расширением» в Edge и выбери «Параметры расширения». Там отображаются состояние привязки, последняя проверка, причина остановки и статус последней попытки. Страница не отправляет сообщения, не повторяет задания и не сохраняет данные переписки. Чтобы открыть панель напрямую, в Microsoft Edge можно использовать пункт «Параметры расширения» после установки версии 0.1.2. Не отключай расширение и не сбрасывай его состояние, если уже была неподтверждённая попытка отправки.
