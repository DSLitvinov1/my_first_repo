Нейрозавод: браузерный агент передачи следующего промпта в выбранный чат.

Это экспериментальный локальный компонент для Chromium (Chrome/Opera) с открытым исходным кодом. В комплекте нет логинов, паролей, платных API или доступа к другим проектам.

Важное ограничение: расширение не установлено и живой ввод сообщения в ChatGPT не проверен. После установки пользователь должен один раз выбрать нужную уже открытую беседу и нажать значок расширения. До привязки агент ничего не отправляет. Повторное нажатие отключает автоматическую отправку.

Агент читает только публичный исходящий файл очередного задания из GitHub, сверяет идентификатор этапа и точный адрес беседы, проверяет отсутствие текста в строке ввода и перед отправкой резервирует идентификатор промпта. Повторная автоматическая попытка для уже зарезервированного промпта запрещена, чтобы избежать дублей. Результат «кнопка отправки нажата» не доказывает успешную доставку сервером.

Установка вручную один раз через режим разработчика и загрузку распакованного расширения. Автоматическую установку в пользовательский браузер со стороны фонового Windows runner не производить: она способна вмешаться в пользовательские программы и не гарантирует нужную авторизованную сессию.

Если интерфейс ChatGPT изменится или конкретная беседа не найдена, агент останавливается и не отправляет сообщение в другой чат.
