# Нейрозавод — утверждённый план реальной разработки

Актуализация: 13 октября 2026. Источник состояния — `roadmap.json`, этот текст поясняет приоритеты и не заменяет машинную проверку.

## Режим проекта
- Самостоятельно улучшать **исходный код самого нейрозавода**, без создания очередных демонстрационных CRM, учебных приложений и повторов уже завершённых учебных задач.
- Ресурсы: бесплатные GitHub Actions, отдельный Windows-мост; первая модель создаёт ограниченное изменение реального кода, вторая независимо анализирует, затем выполняются проверки и разрешённая атомарная публикация.
- Изменять исключительно `bridge/neurofactory/` и предназначенные нейрозаводу файлы `.github/workflows/neurofactory-`. Не менять другие проекты.
- Внешнее автоматическое управление выбранным чатом ChatGPT **отложено пользователем**. Пока не будет отдельного запроса на возобновление, не доставлять задания в браузер и не отмечать этап 02 выполненным.
- Непроверенный, сомнительный и отклонённый код не публиковать; после принятия изменения фиксировать точный коммит и фактические проверки.
- Не повторять опубликованные улучшения. Проверки запускаются при новых изменениях действующего кода, а не ради повторного обучения.

## Пять контрольных этапов

1. **NF-DEV-01 — планировщик и ограничения. ВЫПОЛНЕНО, подтверждено.**
   Версионированные задачи и зависимости, ограничения путей, стабильная очередь следующего задания, запрет повторов, доказательства GitHub и Windows, независимый отзыв второй модели. См. в roadmap `evidence`, проверки 38319773458, 38319734198, 38319439757.
2. **NF-DEV-02 — автоматическая отправка в конкретный ChatGPT. ОТЛОЖЕНО ПО РЕШЕНИЮ ПОЛЬЗОВАТЕЛЯ.**
   Код расширения, ограничение одного чата, защита черновика и повторов, диагностическая страница подготовлены; реальная доставка не доказана, задача **не принята**. Работа над расширением не ведётся до прямого запроса. GitHub outbox в состоянии `paused_by_user`, `no_chat_send`.
3. **NF-DEV-03 — два независимых ИИ реально улучшают исходники нейрозавода. ВЫПОЛНЕНО, подтверждено.**
   Модель Qwen2.5-Coder 7B создала настоящий модуль защиты разрешённых путей, который прошёл 43 проверки. Qwen3 4B независимо проверила реальный кандидат и дала REVIEW_OK после уточнения ошибочного замечания; никакие отклонённые версии не публиковались. Проверенный модуль и доказательства атомарно опубликованы одним GitHub-коммитом 5ec2f935c82a507102afe93b65642d6fdac8edda. Запуск GitHub 38418608193 — успешно. Резервный Windows-мост 38419545229, попытка 2 — успешно, 51 проверка, подтверждены хеш и обе модели. Шаги этапа 02 не были включены.
4. **NF-DEV-04 — восстановление после реального сбоя. В РАБОТЕ.**
   Уже подтверждено: Qwen2.5-Coder подготовила модуль определения возобновляемых задач, Qwen3 независимо одобрила его, проведены 11 предметных проверок и 6 дополнительных проверок на резервном Windows-мосте. Опубликовано исходное изменение 9cfa27a00c6676eaee36a14ebca60eaa9b8bc07b, успешные GitHub и Windows запуски 38421463570 и 38422237905. Это только первый рабочий компонент, не доказательство восстановления после настоящего сбоя.
   Следующая производственная функция: атомарное сохранение очереди, контрольные точки, выдача следующей попытки после прерывания, блокирование повторного исполнения и публикации. Должны быть безопасные ограниченные повторы, исключение параллельной тяжёлой работы, автоматическое продолжение без закрытия программ пользователя. Требуется практическая проверка настоящего прерывания на разрешённой рабочей копии и независимое заключение второй модели, затем Windows-мост. Никаких учебных приложений.
5. **NF-DEV-05 — сквозная приёмка и журнал. ОЖИДАЕТ.**
   Применение цепочки: утверждённое задание → первый агент → независимый второй агент → испытания → GitHub → следующее задание; контроль расходов, отчёт о фактической публикации. Финальная приёмка, включающая доставку ChatGPT, будет ждать возвращения к NF-DEV-02; не подменять отсутствующее подтверждение тестовой имитацией.

## Учёт готовности

Официально завершены **2 из 5 контрольных этапов (40%)**. NF-DEV-01 и NF-DEV-03 подтверждены, NF-DEV-02 отложен исключительно по решению пользователя, NF-DEV-04 активен, NF-DEV-05 ожидает. Нельзя выдавать результат испытания в облаке за успешную публикацию или реальную доставку в ChatGPT.

## Ближайший рабочий цикл

1. Реализовать защиту от потери незавершённых задач: атомарные контрольные точки и восстановление очереди после фактической остановки.
2. Предотвратить повторное исполнение и повторную публикацию, проверять сроки блокировок и сохранение завершённых результатов.
3. Изолировать генерируемые изменения нейрозавода; получить независимую проверку второй моделью.
4. Подтвердить прерывание, восстановление и отсутствие дублирования через GitHub и резервный Windows-мост.
5. После принятия этапа 04 приступить к полной приёмке доступной автономной части; доставку в ChatGPT оставить отложенной.

Каждый пользовательский отчёт: подтверждённые изменения, фактическая готовность, препятствия и **следующий готовый промпт**.
