НЕЙРОЗАВОД — порядок допуска изменений к интеграции
Дата контрольной проверки: 14.10.2026
Владелец: координирующий чат, только координационная ветка.

Этот порядок не даёт права автоматически объединять изменения. Он лишь формализует требования к отдельной независимой приёмке.

Условия допуска:
1. Источник — один из пяти закреплённых чатов, только его рабочая ветка и файлы из lanes.json.
2. Цель — утверждённая ветка разработки «Нейрозавода», без подмены репозитория или подключения других проектов.
3. Заявка не является черновиком; GitHub подтверждает отсутствие конфликта.
4. Все изменённые пути, включая исходное имя переименованного файла, принадлежат одному владельцу.
5. Одобрение предоставлено независимым GitHub-проверяющим, не автором, именно для актуального коммита. Отклонённое одобрение или открытые замечания об исправлениях блокируют допуск.
6. Проверки принадлежности файла и независимый контроль Qwen3 завершились успешно именно для актуального коммита. Отчёт должен ссылаться на подлинный GitHub Actions, а не на запись из текста первого агента.
7. Фактический вывод Qwen3 и контрольная сумма проверенного исходника требуют отдельной независимой сверки. Одного формально успешного статуса CI недостаточно для доказательства содержимого заключения.
8. Любое изменение коммита после проверки отменяет допуск.
9. Итоги Windows и GitHub сохраняются отдельно; публикация возможна только через надёжного издателя после полной сверки квитанций. Никакого автоматического возобновления при неизвестном состоянии публикации.
10. Доставка сообщений в ChatGPT остаётся выключенной, платные API запрещены, пятый этап остаётся открытым.

Защита основной ветки: GitHub на момент проверки сообщает protected=false. Чтение настроек защиты через подключённый доступ отклонено с ошибкой 403. Поэтому проверки пока консультационные: они НЕ гарантируют, что пользователь с правом записи не выполнит ручное объединение в обход. Необходимо настроить правила репозитория с обязательным CI и независимым одобрением, после чего проверить их отдельным безопасным испытанием.

Открытый конфликт: черновик № 2 содержит вместе изменения CORE и REVIEW плюс два workflow без закреплённого владельца. GitHub сообщает mergeable=true, но по правилам «Нейрозавода» это НЕ разрешение на объединение. Приёмка блокируется до разделения файлов на отдельные заявки, закрепления сценариев проверки за владельцами и прохождения независимых тестов.

Текущая проверка: read-only premerge_gate.py и test_premerge_gate.py, workflow neurofactory-coordination-premerge.yml. Ни одна из проверок не объединяет и не публикует чужие результаты.

Изменения в другом чате: согласование следует вести в GitHub Issue № 3 с точной веткой, файлами, номером испытания и причиной блокировки. Прямые изменения чужого кода запрещены.
