## Ограничения и обязательная независимая приёмка

- Этот установочный сценарий **целенаправленно запрещён на пользовательском или self-hosted Windows ПК**. Эксплуатационный Windows MSI/Inno с подписью издателя, независимой цепочкой доверия и утверждённой процедурой обновления пока не готов; CI-сценарий **не должен использоваться как инструкция установить на ПК владельца**.
- Проверка SHA и метаданных сама по себе не устанавливает подлинность подписанта или ревизора; без независимо заверенного выпуска она не делает пакет доверенным. Скрипт реальной установки должен включать отдельную проверку подлинности издателя и подписанное распоряжение владельца до разрешения SCM.
- Дежурная служба не является постоянным исполняющим CORE-HOST. В ней нет очереди, подписанта owner, сетевого listener, внешнего witness или логики применения результата Qwen. Она запускается вручную для лабораторной проверки механики SCM.
- Отдельная проверка настоящей Qwen → signed CORE → отдельной реальной restricted SCM с тестовым безвредным результатом уже проведена [run №39762142770](https://github.com/DSLitvinov1/my_first_repo/actions/runs/39762142770) в PR №62. Её не повторяли.
- Для полноценного готового релиза остаются: independently provisioned Windows publisher cert и owner/reviewer/witness public-key roots с защищёнными private-key custody; независимый monotonic highwater вне откатываемого диска; защищённое обновление/revoke/rollback; исполняющий постоянно работающий CORE-HOST с реальным owner-approved задачами; физический конец-в-конец на точном целевом ПК; **независимое подписанное одобрение Issue №11 на точную сборку**. До этого **NO MERGE / NO PRODUCTION INSTALL / NO ACTIVE QUEUE / NO SKILLS / NO AUTO-APPLY**.
