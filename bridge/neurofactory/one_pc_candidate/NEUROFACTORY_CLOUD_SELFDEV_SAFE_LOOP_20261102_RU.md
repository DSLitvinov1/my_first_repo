## Новый безопасный self-development research module

Файл `selfdev_cloud_research.py`:
- Перед каждым обращением проверяет **точный SHA модели и runtime**, реальное исходное Git HEAD и отсутствие даже неотслеживаемых файлов в checkout; входные темы только из встроенного allowlist `host_recovery`, `selfdev_review`, `installer_rollback`.
- Запускает модель как локальный subprocess без `shell`, с фиксированными CLI опциями (CPU/контекст/токены/тайм-аут), без экспортированных GitHub/SSH/API секретов, в отдельной папке, без модели-инструментов.
- Не воспринимает текст Qwen как доверенные команды; строго ограничивает размер ответа, отделяет prompt-echo от ответа, фиксирует модель/SHA/исходный SHA и хэш результата.
- Сохраняет только **недоверенное предложение** в приватном `0600` JSON с `UNTRUSTED_QWEN_RESEARCH_NO_APPLY`, `production_release_allowed=false`, `automatic_pr_created=false`, `host_task_effect_allowed=false`.
- Запрещает совместить writable research folder с Git checkout, world-readable evidence, непроверенную модель/исполняемый файл или исходник с незакоммиченными/неотслеживаемыми изменениями. НЕ изменяет код, не создаёт PR, не включает службу/очередь.
- Наблюдение: runtime работает под обычной Linux-учётной записью; **это не доказательство дополнительной ОС-песочницы, ограничения сетевого стека или изоляции от всех файлов этого пользователя**. Нужна отдельная OS-песочница для повышения допуска.
