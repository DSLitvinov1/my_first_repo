## Что это подтверждает и чего НЕ подтверждает

**Фактически подтверждено на двух машинах:** реальный ограниченный Windows-SCM запуск, связь с реальным вторым Linux по pinned SSH host+Ed25519, точная scope-проверка, durable local UNKNOWN до удалённого ACK, Linux monotonic epoch0→1, одна подписанная пользователем безвредная операция, совпадающий по байтам output, durable EXECUTED и отсутствие второго эффекта после stop/start службы.

**Не следует считать сделанным:** полную перезагрузку всей ОС Windows и проверку SCM после **холодного Windows reboot** (пока проверялись только настоящие SCM stop/start); сторонний доверенный независимый WORM/HSM оператор Linux (это Linux под тем же владельцем, не независимое хранение); действительный коммерческий Authenticode сертификат и подпись установщика; положительную независимую оценку стороннего уполномоченного аудитора; любые произвольные действия CORE/Qwen/браузера/установку SKILLS без отдельного разрешения. **Текущий HOST ограничен единственным действием `write_note`, а Qwen3.5 9B генерирует только сохраняемые `PROPOSED_UNVERIFIED` черновики**.
