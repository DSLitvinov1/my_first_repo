## Содержание предложения и оценка качества

Qwen предложила добавить регулярную проверку идентификатора проекта `row[1]` в `_one_draft` и отрицательный тест на неправильный ID.

**Отдельная техническая проверка выявила реальные недостатки**:
1. Предложено `re.IGNORECASE`. Это разрешает заглавные A–F, хотя наша политика принимает только 32 **строчных** шестнадцатеричных символа. Таким образом, предложенный флаг недопустим.
2. Предложен `ValueError`, тогда как публичная доверенная граница проекта использует `AdmissionDenied` и должна отказывать штатным типом.
3. Предложенный тест содержит `pass` и предполагает неподтверждённую сигнатуру `_one_draft`; он не создаёт реальную повреждённую строку SQLite и не проверяет отсутствие записи в настоящем CORE.
4. Никакой реальный patch или прошедший тест модель не создала. Текст и hash — только `PROPOSED_UNVERIFIED_REVIEW_ONLY`.

Значит, **предложение действительно создано настоящей Qwen, но оно не одобрено и не может применяться к исходникам**. Кандидат исправления должен подготовить отдельный разработчик, добавив точную проверку `[a-f0-9]{32}` без case-insensitive, `AdmissionDenied` и полноценный тест с настоящим SQLite, затем передать на независимый REVIEW.

## Обоснование архитектуры и ограничения

- Авторизационный пакет PR №43 допускает только `ONE_TEST_CORE_ENQUEUE_NO_EXECUTION`. Отдельная разовая генерация выполнялась по явно ограждённому **другому** CI-only разрешению, НЕ по расширенным правам владельца.
- `core.provider_preview` — read-only предложение для провайдера, не передача полномочий выполнить работу над файловой системой. Провайдеру доступны только задача и короткое описание фрагмента, но не ключ владельца.
- Для Q951 строгий file-write JSON формат дал реальный, но непрошедший проверку ответ; для Q952 более длинный ответ был UNKNOWN/truncated и не повторялся. Q953 выделено как новая ограниченная учебная задача после анализа ошибки формата.
- В реальной системе **обязательно** подготовить защищённый, выделенный и независимо одобренный компонент owner-key custody на одном Windows ПК. Отдельно проверить отсутствие ошибок cross-DB checkpoint, права службы, восстановление и ограничение полного отката диска.
- SKILLS PR №558 не активирован, независимый REVIEW №11 по этой ветви отсутствует, PR не объединять.

**Итог:** первая настоящая самостоятельная локальная генерация по подписанному CORE заданию подтверждена; исправление исходника НЕ ПРИНЯТО. RELEASE=false, OWNER_PC_CHANGED=false.
