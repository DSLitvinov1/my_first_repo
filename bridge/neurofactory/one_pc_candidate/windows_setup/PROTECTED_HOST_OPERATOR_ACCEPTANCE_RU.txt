НЕЙРОЗАВОД — ЗАЩИЩЁННАЯ WINDOWS-СЛУЖБА. ПАКЕТ ДЛЯ ПРИЁМКИ.
Контрольный выпуск: октябрь 2026. СТАТУС: НЕ ПОДПИСАН / НЕ РАЗРЕШЁН К ПРОДАКШНУ.

1. Этот архив предназначен для независимого аудита и проверки
   установочного процесса, но НЕ является готовым установщиком.
   Запрещено запускать службу на пользовательском компьютере,
   пока не завершены подлинная проверка подписанного издателя,
   выдача защищённых ключей и заключение независимого ревизора.
2. Внутри размещён официальный Python 3.12.10 с закреплённой
   контрольной суммой, собственный исходный модуль Windows SCM,
   строго неактивная конфигурация, файл сведений о составе.
   Нет и не должно быть owner_private, API токенов, подписантов,
   сторонних скрытых учётных данных или входящего сетевого слушателя.
3. Служба NeurofactoryCoreHost реализует только защищённый процесс,
   корректный запуск/остановку и диагностику. Важное ограничение:
   она НЕ выполняет Qwen-задания, НЕ запускает CORE очередь,
   НЕ создаёт/меняет файлы проектов и НЕ публикует работы Codex/Sites.
4. Проверенные реальные облачные испытания ограниченного Windows SCM:
   https://github.com/DSLitvinov1/my_first_repo/actions/runs/39757521730
   Запуск, отдельный Service SID, LocalService, ACL каталога, запись
   статуса, отказ после подмены разрешения, остановка и перезапуск.
5. Независимому ревизору надлежит проверить точный SHA исходника
   и этого архива, код установки, код службы, реальную подпись
   издателя Authenticode, ACL, права и целевую версию Windows.
   В настоящем архиве нет производственной подписи или witness.
6. Только выделенный уполномоченный оператор должен настраивать
   службу после выдачи ключей, положительной REVIEW, резервных
   копий и независимого свидетеля состояния. НЕ переиспользовать
   CI-конфигурацию или test signers как реальных владельцев.
7. Отсутствующие требования: промышленная подпись и журнал выпуска,
   независимые owner/reviewer/witness ключи и antirollback, защищённая
   авторизация каждой операции, физический непрерывный Qwen→CORE→HOST
   тест и подтверждённые восстановление/повтор без эффекта.
   Положительные результаты лабораторной службы их НЕ доказывают.

Никакой автоматической установки на Windows-ПК пользователя нет.
