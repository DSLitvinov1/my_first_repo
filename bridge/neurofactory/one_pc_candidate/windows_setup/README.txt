НЕЙРОЗАВОД — ЛОКАЛЬНАЯ БАЗА, ПРЕДРЕЛИЗ

Версия 0.1: проекты, черновики заданий, история, резервная копия SQLite
и проверка наличия локальной модели Ollama. Все данные остаются
на одном Windows-компьютере по адресу:
%LOCALAPPDATA%\NeurofactoryData

Чтобы открыть: запустите ярлык НЕЙРОЗАВОД — Локальная база.
В браузере откройте http://127.0.0.1:8766/.
Закройте окно приложения, чтобы остановить сервер.

Рабочая очередь CORE, реальное выполнение моделей, защищённая служба HOST
и публикация НЕ АКТИВНЫ. Это не полноценный готовый «НЕЙРОЗАВОД».
Обновление и удаление программы не должны удалять пользовательские данные
из %LOCALAPPDATA%\NeurofactoryData. Перед удалением сохраните резервную копию.
Никакой автоматической загрузки Ollama или моделей нет.
Для активации реальных операций потребуется отдельное одобрение.
