НЕЙРОЗАВОД — ОГРАНИЧЕННЫЙ WINDOWS-КАНДИДАТ 0.1.1

Это реальная локальная программа для сохранения проектов, черновиков заданий,
истории, резервных копий SQLite и явной проверки ответа установленной Qwen.
Никакие производственные задания не запускаются.

В установку добавлены точные исходные компоненты CORE, испытательного HOST,
PROVIDERS и COORDINATOR с контрольными суммами и источниками Git-коммитов.
Проверка контрольных сумм обязательна при запуске. Она проверяет целостность
компонентов, но не делает их исполняемыми, авторизованными или независимо
проверенными.

ВНИМАНИЕ: защищённая Windows-служба НЕ устанавливается и НЕ запускается;
реальная очередь CORE НЕ подключена к пользовательским черновикам;
цикл HOST->CORE->UI НЕ работает из установленной программы;
настоящая генерация Qwen этим установщиком НЕ подтверждена.
Ограниченная тестовая служба в комплекте предназначена только для изолированного
CI и не может быть активирована пользователем как производственная.

Данные: %LOCALAPPDATA%\NeurofactoryData
Откройте ярлык «НЕЙРОЗАВОД — Локальная база».
В браузере: http://127.0.0.1:8766/
Закройте окно приложения для остановки сервера.

Обновление и удаление не должны удалять пользовательские данные.
Сделайте резервную копию перед удалением или сменой версии.
Никакой автоматической загрузки Ollama/Qwen и платных API нет.
Нужны отдельная независимая приёмка и одобрение владельца перед
установкой защищённой службы и производственным запуском.
