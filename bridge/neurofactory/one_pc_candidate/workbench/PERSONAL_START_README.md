# Личный Work ONE — пробный изолированный запуск

Этот пакет предназначен для собственного компьютера. Не устанавливается как служба Windows, не обновляет действующую версию «Нейрозавода», не меняет CORE9/HOST, Linux witness, CRM или проекты клиентов.

Для тестового запуска необходим установленный **Python 3.11 или новее**. Распакуй папку и запусти `START_PRIVATE_WORK_ONE.ps1` в обычной Windows-сессии (без прав администратора). Адрес интерфейса: `http://127.0.0.1:18770/`. Данные хранятся отдельно в `LOCALAPPDATA\NeirozavodWorkONEPrivatePilot`.

Это **не полностью автономный агент**: для использования браузерного исполнителя понадобятся Node.js, Puppeteer и Chromium; для Qwen — отдельно защищённый локальный доступ к модели; для Google/Bitrix24 — отдельная авторизация аккаунтов. По умолчанию все эти доступы выключены. Проверяй раздел «Личная готовность».

Пакет не содержит закрытых ключей, OAuth-токенов, учётных записей, базы клиента или пользовательских файлов. Ни один резервный SSH forced-command канал не предназначен для произвольного выполнения команд или управления мышью и клавиатурой.

Этот вариант **не требует коммерческого релиза**. Прежде чем пользоваться им как основным помощником, необходимо провести физическую проверку Windows, защиту состояния, реальную проверку Qwen и одну разрешённую сквозную задачу.


## Самопроверка и пробное управление Windows

В новой версии комплект содержит `private_preflight_one.py`: перед запуском он **только читает** SHA256-манифест пакета, сравнивает все файлы и проверяет, работает ли личный Work по 127.0.0.1. Он не касается файлов заказчиков, не запускает Qwen и не создаёт записи в сервисах.

Для отдельного испытания мыши и клавиатуры запусти тот же `START_PRIVATE_WORK_ONE.ps1` с параметром `-NotepadTest` **в собственной интерактивной пользовательской сессии Windows**. Это явное разрешение только для `notepad.exe`: автоматически откроется тестовый файл `ONE-SYNTHETIC-NOTEPAD-TEST.txt` в отдельной папке личного Work. В терминале появится номер процесса. Создай новый пустой проект в интерфейсе Work, открой блок «Рабочий стол Windows», нажми «Найти окна» и выбери **только тестовый процесс с указанным PID**. Прикрепи окно, сделай снимок, включи разрешённые клики по снимку и попробуй напечатать синтетическую строку. Не выбирай окна с настоящими пользовательскими заметками или паролями. Запись не отправляется в Google или Битрикс24.

**Важно:** это режим ручной приёмки управления Windows. Полноценная самостоятельная цепочка Work ONE → Qwen → Windows с реальной моделью ещё не прошла физическую приёмку; наличие локальной модели или GitHub-тестов не заменяет её.

Если запускаешь обычный режим без `-NotepadTest`, возможности мыши и клавиатуры останутся выключенными. Существующий «Нейрозавод» на портах 8766/8770 сохраняется; тестовый интерфейс работает отдельно на 18770.

Последний пароль/ключ для сервера, резервного моста или OAuth **не копируй** в эту папку и не присылай в чат. Ограниченный личный SSH witness нельзя использовать вместо Desktop Commander для произвольных команд.
