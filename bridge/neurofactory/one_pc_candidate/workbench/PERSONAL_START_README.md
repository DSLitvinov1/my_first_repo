# Личный Work ONE — пробный изолированный запуск

Этот пакет предназначен для собственного компьютера. Не устанавливается как служба Windows, не обновляет действующую версию «Нейрозавода», не меняет CORE9/HOST, Linux witness, CRM или проекты клиентов.

Для тестового запуска необходим установленный **Python 3.11 или новее**. Распакуй папку и запусти `START_PRIVATE_WORK_ONE.ps1` в обычной Windows-сессии (без прав администратора). Адрес интерфейса: `http://127.0.0.1:18770/`. Данные хранятся отдельно в `LOCALAPPDATA\NeirozavodWorkONEPrivatePilot`.

Это **не полностью автономный агент**: для использования браузерного исполнителя понадобятся Node.js, Puppeteer и Chromium; для Qwen — отдельно защищённый локальный доступ к модели; для Google/Bitrix24 — отдельная авторизация аккаунтов. По умолчанию все эти доступы выключены. Проверяй раздел «Личная готовность».

Пакет не содержит закрытых ключей, OAuth-токенов, учётных записей, базы клиента или пользовательских файлов. Ни один резервный SSH forced-command канал не предназначен для произвольного выполнения команд или управления мышью и клавиатурой.

Этот вариант **не требует коммерческого релиза**. Прежде чем пользоваться им как основным помощником, необходимо провести физическую проверку Windows, защиту состояния, реальную проверку Qwen и одну разрешённую сквозную задачу.
