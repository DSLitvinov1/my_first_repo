# NEIROZAVOD Work ONE 0.4 — клавиатура браузера

Дата: 13 ноября 2026. Основа: PR #107, коммит 1c63bcfc0e2ade55aaf3b66dedf4e94342629926.

## Разработано
- Встроено в существующий Work ONE, без замены CORE9/HOST или рабочих Windows-служб.
- Браузерная клавиатура: выбор видимого поля мышью, русскоязычный ввод,
  замена/добавление текста, Tab и безопасные навигационные клавиши.
- Одним пользовательским действием можно выбрать поле и ввести подготовленный
  текст через действие fill. Для поиска полей есть список с подписями.
- API доступен только с ранее существующими проверками владельца, Origin и Host,
  по ID проекта и временной сессии браузера. Текст не записывается в журнал.
- Запрещены автоматическая отправка форм, Enter, пароли, 2FA, платёжные поля,
  произвольные скрипты и системные команды; браузер пока только изолированный.
- Быстрое чтение карточек и создание задач Битрикс24 пока не подключены:
  нужны авторизация, разрешённая интеграция CRM, согласование записи,
  подтверждение созданной задачи и безопасность персональных данных.

## Ограничения
Нет глобального управления клавиатурой Windows, нет автономного Qwen-планировщика,
авторизованного Bitrix24, записи реальных задач и независимой приёмки,
публикации/установки новой Windows-сборки. Пилот остаётся DRAFT.
При производственном использовании необходим OS-level sandbox и
отдельные разрешения на действие с CRM.
