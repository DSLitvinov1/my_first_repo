## Критические ограничения перед настоящей Windows-службой

- Изолированный GitHub-hosted Windows Runner, где worker и recipient временно использовали **одну и ту же Windows SID**. Настоящее разделение Service SID / ACL и защищённого каталога службы ещё не испытывалось.
- Сервер выполняется один раз внутри тестового Python-процесса. **Не является зарегистрированной или постоянно действующей Windows SCM Service**. Код из этого теста не устанавливать как production-службу.
- Учебный Ed25519 ключ создан внутри CI. Отдельный авторизованный владелец, аппаратная Windows CNG/TPM custody, независимый оператор/действующая ACL GitHub и внешняя подпись REVIEW не подтверждены.
- Данные CORE SQLite можно откатить; один локальный marker также можно откатить вместе с диском. Отдельного независимого внешнего monotonic witness/HSM ещё нет.
- Ограничение на единственное имя `windows_pilot.txt` и временную папку — намеренная защита от записи в настоящие проекты. Не расширять разрешённые пути без нового отдельного аудита.
- Нет реальной перезагрузки Windows ПК, пользовательского установки или старта рабочей очереди.
- Windows Desktop Commander сопряжён с одним ПК, но удалённые команды ограничены квотой; его не перезапускали/не пытались обходить.
