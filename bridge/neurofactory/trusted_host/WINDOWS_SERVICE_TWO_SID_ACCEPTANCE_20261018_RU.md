# НЕЙРОЗАВОД — Windows Service candidate и реальная приёмка двух учётных записей

Дата: 18.10.2026. Применимость: отдельная изолированная ветка `neurofactory-windows-service-isolation-20261018`. Не предназначено для автоматической установки или публикации.

## Подтверждено на GitHub-hosted Windows 2025

Выполнен настоящий ранее подготовленный сквозной учебный сценарий CORE → Windows Named Pipe → файл `windows_pilot.txt`, [CI №39111299195](https://github.com/DSLitvinov1/my_first_repo/actions/runs/39111299195) — 5/5 PASS, точный CORE `beb08eff32923d8ca364aabfde0458f380acf8e7`, HOST `cc4734b64beb66babdf742e86ccfe86bfe3e2c73`. Один тестовый пользователь Windows, ключ внутри CI, нет настоящей защиты сервиса от прав исполнителя. Прямой writer CORE запрещён.

Добавлен `windows_sandbox_service_candidate.py`: класс Windows SCM Service под отдельную службу `NeurofactorySandboxReceiver`, ограничение изначально одним учебным файлом, загрузка однозначной конфигурации и **только публичного** Ed25519 ключа. Не выдаёт прав на производственный запуск, не устанавливает службу, не изменяет ACL, не создаёт и не сохраняет реальные приватные ключи. Назначение operator-approved-install внутри JSON **не является** криптографическим подтверждением полномочий, поэтому сам по себе этот конфигурационный файл не может разрешить запуск или установку. Для производственной службы нужен отдельный уполномоченный внешний установщик и независимая аттестация ACL.

[CI №39113054424](https://github.com/DSLitvinov1/my_first_repo/actions/runs/39113054424) — 6/6 PASS, тесты изолированного конфигурационного допуска и запрета повторной записи из UNKNOWN. **Это программная проверка, а не системный тест SCM под двумя пользователями и не фактическое аварийное восстановление после reboot.**

## Что требуется для настоящей проверки двух SID

1. Независимый владелец компьютера утверждает тестовые учётные записи: отдельный `NT SERVICE\\NeurofactorySandboxReceiver` или выделенный неприоритетный service account для получателя и отдельный без административных прав worker account CORE. Нельзя помещать GitHub Runner в Administrators, вручать ему приватный ключ владельца, Service Control Manager управление, права записи в конфигурацию и каталог получателя.
2. Надёжный Windows-установщик *после отдельной авторизации* создаёт SCM Service, настраивает service SID, запрет изменения бинарного файла и доверенной конфигурации из worker, явную DACL Named Pipe и NTFS ACL для защищённого каталога, проверяет видимые Windows token группы и ACE; внешний оператор удерживает приватные ключи отдельно от CORE. Не принимать один Windows SID в обеих тестовых нитях за разделение прав.
3. Провести через две реальные учётные записи: успешный доступ только worker SID к именованному каналу, успешная проверка owner-grant на стороне службы и один инертный файл; другой SID, Everyone/Anonymous и неавторизованный пользователь должны получить отказ до создания файла. Передача владельческого private key по CORE запрещена — текущая учебная функция signer-in-CI не предназначена для установки.
4. Проверить повторную доставку, чужую подпись, истёкшую аренду, изменение target/hash/operation, подмену Junction/reparse point и file hardlink, неизвестную операцию после crash между fsync и окончательной квитанцией, восстановление после настоящего рестарта Windows-службы и после согласованной перезагрузки компьютера.
5. Восстановить тестовую PostgreSQL или SQLite из старого снимка, повторить тот же запрос и проверить запрет повторной операции у отдельно расположенного доверенного свидетеля. ВАЖНО: локальный журнал на одном диске не защищает от полного отката диска или компрометации администратора.
6. Передать точные Git SHA, журналы двух SID, квитанции/подписи и инертный результат отдельному уполномоченному REVIEW. Пока нет этих результатов, оставить `REJECT LIVE`, `HANDOFF PAUSED_BY_USER`.

Через резервный мост виден единственный Windows компьютер `WIN-LIDC05TBOQD`, online; команды Desktop Commander ранее были ограничены месячной квотой, поэтому ни смена ACL/учётных записей, ни системная установка, ни перезагрузка **не производились**.
