# Второе учебное приложение — калькулятор упаковок

Все данные вымышленные. Приложение вычисляет объём коробки и количество коробок для партии предметов.
Пример: python main.py 2 3 4 11 4
Ожидаемый результат: 24 3

Части volume.py и boxes.py должен самостоятельно создать локальный Qwen2.5-Coder на временном бесплатном облачном исполнителе.
main.py и test_app.py — независимые заранее заданные шаблоны, а не код нейросети. Итог публикуется только после всех проверок и подтверждения второй Qwen.
