Учебное техническое задание: консольная мини-CRM для вымышленных заявок. Требуется самостоятельно спланировать архитектуру и написать ВСЕ три взаимосвязанных Python-модуля с нуля: storage.py, crm.py, main.py. Разрешена только стандартная библиотека Python. Класс CRM(path) в crm.py должен поддерживать add(name, phone, note='') с возвратом словаря и уникальным целочисленным id, all() со списком словарей, search(query) без учёта регистра по имени, телефону и заметке, edit(id, name=None, phone=None, note=None) для обновления полей, set_status(id, status) для изменения статуса между new, in_progress и done. Новая заявка получает статус new. Изменения должны сразу сохраняться в JSON на диске, повторное создание CRM(path) восстанавливает записи. Поиск и редактирование не должны менять остальные заявки. main.py должен реализовать простой интерфейс командной строки add, list, search, edit, status; путь к JSON задаётся аргументом --db, по умолчанию crm.json. Нельзя использовать настоящие контакты, сетевые запросы и секреты. Модули должны работать совместно, выдержать независимые тесты и получить одобрение второго ИИ.
