# НЕЙРОЗАВОД — изолированная UI-панель (демо)

Статическая русскоязычная панель наблюдения, без зависимостей, сети и серверной части. Для локального просмотра открыть `index.html` из каталога (рядом `styles.css`, `app.js`, `demo-data.js`) в актуальном Chrome/Firefox/Safari. Никаких серверных ключей, API, очередей, моделей и платных запросов нет.

Девять разделов: обзор, проекты, очередь, исполнители, ошибки, контрольные точки, независимая проверка, конкретное задание, локальный проект-кандидат. Все строки примера помечены ДЕМОНСТРАЦИЯ / NOT_VERIFIED / UNKNOWN. Локально созданные кандидаты существуют исключительно в памяти вкладки и исчезают после её перезагрузки.

Файл `demo-bundle.json` — учебный образец схемы `neurofactory_ops_ui_readonly_bundle` (OPS source SHA e32acaba8a3c6b5dc724cc08c84ad033190b9efe), но НЕ телеметрия работающей системы. `demo-data.js` содержит тот же объект для безопасной работы даже из `file://` без запросов в сеть. Кнопка «Импорт JSON» принимает локально переданный ранее созданный OPS bundle, проверяет его форму, полный набор запретов и дублирование JSON-ключей, оставляя все данные неаттестованными.

Отказоустойчивость: CSP блокирует сеть и inline scripts, все внешние значения попадают в интерфейс через textContent, включены ограничения размера и вложенности импортируемого JSON. Не предусмотрены доверенная подпись источника, реальный источник GitHub/Windows, кнопки управления или сохранение проекта.

Назначение: только независимый просмотр и интерфейсный smoke test. Нельзя подключать live telemetry, авторизацию или управление до отдельного решения координатора и независимой приёмки. Все файлы UI принадлежат только `bridge/neurofactory/control_ui/`.
